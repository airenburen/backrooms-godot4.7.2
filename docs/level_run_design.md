# Level !「红色狂奔」重做设计文档

> 目标观感：一条漫长得没有尽头的酒店走廊，暗红应急灯把一切染成血色，
> 地面湿黑如镜、把灯光拉成长条反光；翻倒的文件柜和桌子横在路边，
> 两侧是永远打不开的客房门；尽头一块 EXIT 牌在红光里发绿——
> 而你身后，有什么正沿着这条走廊追上来。
> 参考图三张：湿黑反光长廊 / 翻倒文件柜路障 / 尽头 EXIT 与两侧客房门。

## 1. 现状问题（为什么现在只是"红色版 L0"）

当前 Level ! = 基类直道（中间 3 格 × 47 格）+ 两侧壁挂红灯。与经典 L ! 的差距：

| 经典 Level ! | 现状 |
|---|---|
| **湿黑镜面地面**，红灯拉成长条反光 | 哑光暗红混凝土，无反射 |
| **翻倒家具路障**（文件柜/桌子斜插走廊） | 空荡荡一条道，啥都没有 |
| **两侧客房门**（打不开，纯压迫） | 光墙 |
| **墙裙腰线**（下半深色，酒店感） | 上下一个色 |
| 尽头**一扇门 + 上方 EXIT 牌** | 黑洞口（沿用 L0 出口观感） |
| **身后有东西在追**（核心张力） | 无，纯跑步机 |

## 2. 核心决策：追逐怎么做（三档，拍板选一档）

经典 L ! 的灵魂是"被实体追杀"。但本项目是纯环境恐怖、无 AI/寻路系统，
追逐方案直接决定工作量与风险，列三档：

### 方案 A — 纯氛围追逐（**推荐**，零实体）
不做任何会动的怪物，全靠**声光**营造"身后有东西"：
- **灯光依次熄灭逼近**：玩家身后 N 米内的壁灯一盏盏灭掉，黑暗追着脚步蔓延。
  纯脚本，`_physics_process` 每帧比对玩家 z 坐标与灯 z 坐标，落后玩家 X 米即 `light.visible=false`。
- **渐强低吼**：新增程序化音效 `create_entity_growl()`（低频噪声 + 缓慢振幅包络循环），
  音量随"玩家已跑距离"线性增大；靠近出口时音高上扬、节奏变急（制造"它追上来了"）。
- **屏幕边缘红脉冲**：越接近出口，`ColorRect` 暗角红闪越频繁（心跳感）。
- 优点：零寻路、零穿模风险、零性能开销，且"看不见的追逐"比看得见更瘆人。

### 方案 B — 轻量剪影追逐（A + 一个不会动的黑影）
在 A 基础上，走廊尽头玩家身后生成一个**黑色人形剪影**（SimpleMesh 拉伸盒体组合，
无碰撞、不寻路），沿 z 轴以"略慢于玩家冲刺"的匀速推进——玩家跑得快它就追不上，
一旦减速（体力耗尽）它就逼近、触发贴背低吼。纯视觉 + 距离判定，不做真实 AI。

### 方案 C — 完整实体（**否决**）
会寻路、会堵门、有碰撞体积的怪物。过度工程：需要 NavigationServer、状态机、
受击判定，与"一条直线走廊"的极简关卡气质冲突，且极易卡在路障上。列入不做清单。

> **默认按方案 A 实现**；文档 §5 的钩子映射预留 B 的剪影生成点（一个函数，随时可加）。

## 3. 视觉支柱与实现方案

### 3.1 布局：收窄 + 两侧客房门凹位

- 走廊**中间 3 格（10.5m）太宽**，不像逃命走廊。改 `RUN_WIDTH` 使中间通道 = **2 格（7m）**；
  有效通行宽度靠 §3.3 的路障 + §3.4 的门框出挑挤压到视觉 4~5m，不动 cell_size。
- **两侧客房门**：每 2 格在左右墙嵌一扇"打不开的门"——门框（深色金属，出墙 6cm）
  + 门板（暗红木纹，带百叶/把手细节用 CSG 薄板拼）+ 门牌（`Label3D` 房间号 "114"…）。
  门是**假门**：纯贴墙装饰，无碰撞、不可交互（`use_collision=false`）。
  覆盖 `_emit_wall` 钩子（L0 用它画踢脚线、L2 挂管线、这里嵌门，互不干扰）。

### 3.2 湿黑镜面地面（复用 L1 shader 方案）

- 直接复用 `level_1.gd` 的 `WET_SHADER` 内联字符串思路，**调参不改结构**：
  基色压到近黑（`Color(0.04,0.02,0.02)`），水洼阈值调低让**整片地面近乎全湿**
  （不是 L1 的斑驳水洼，是均匀的湿），粗糙度 0.03、镜面高光拉满——
  红灯在地面拉出连续长条反光，就是参考图 1/2 的黑镜面。
- 覆盖 `_build_floors`（L1 已验证的覆盖点）或直接 `_create_materials` 里替换 `_floor_mat`。

### 3.3 翻倒家具路障（图 2 签名景观）

- 每 6~9 格放一件**倒伏路障**，全部靠墙、**绝不封死主通道**（留 ≥2.5m 可跑缝隙）：
  - **文件柜**：CSGBox 柜体 + 3 层抽屉面板（略拉开），整体侧倒 80°、斜插向墙。
  - **长条桌**：桌面薄板 + 4 腿，翻倒横陈，靠墙一侧抬起。
  - **散落纸张**：地面 3~6 片白色 `CSGBox3D`（0.2×0.005×0.28，随机旋转）点缀。
- 材质：金属柜体（复用 run_wall 色系，压暗）、桌面暗红。全部**无碰撞**——
  狂奔中撞到会卡住摔停，破坏"逃命"手感；纯视觉擦身而过即可。
- 生成点：`_custom_build`，沿 z 步进撒点，避开出口前 3 格（别挡住终点观感）。

### 3.4 墙裙腰线 + 天花板红灯板

- **墙裙**：`_emit_wall` 里沿墙根到 1.1m 高度贴一条深色带（比主墙暗 40%），
  上方 1.1m 处一条 3cm 腰线木条——酒店走廊的"下半深色"分层感（图 2 清晰可见）。
- **天花板红灯板**：每隔几格顶棚嵌一块红色发光板（区别于两侧壁灯），
  对应图 2 顶部那块长方形红灯；与 §2 的"灯光熄灭"系统绑定（顶板也纳入熄灭序列）。

### 3.5 出口：尽头门 + EXIT 牌（图 3）

- 覆盖 `_place_exit`：走廊尽头**一面墙 + 一扇关着的门 + 门上方绿色 EXIT 灯箱**。
  - 门：暗红双开或单开门板（CSG），无碰撞，纯视觉终点。
  - EXIT 灯箱：`Label3D` "EXIT" 绿光（emission），在满走廊红光里唯一冷色，
    一眼锁定终点——这是"逃出去了"的信号。
- **闸门逻辑保留**：集齐杏仁水才放行（§2 系统已全局接入，本关不改）。
  但 L ! 是直线，3 瓶杏仁水就撒在走廊沿途（当"边逃命边捡"的节奏点，不额外探索）。

## 4. 参数速查（level_run.gd `_init`，相对现状的改动加粗）

```
cell_size 3.5 · wall_height 3.2 · RUN_WIDTH **4**（中间 2 格=7m 通道）· RUN_LENGTH 49
volumetric_fog_density **0.028**（血色薄雾，比现在略浓，增强灯光体积感）
dust_count 300 · dust_extents **Vector3(3, 1.4, 3)**（收窄匹配走廊）
hum_volume_db -13.0 · hum_pitch 0.9 · **growl 追逐低吼（新增，见 §2A）**
壁挂灯：range **7.0**（收窄走廊，缩短照程更压抑）· 能量 1.3 · 熄灭逼近（§2A）
路障：每 6~9 格 · 客房门：每 2 格 · 杏仁水 3（沿途撒点）· 电池 3
level_title "Level !" · hint_text "RUN. IT'S BEHIND YOU."
```

## 5. 实现钩子映射（动代码时照此执行）

| 内容 | 位置 | 方式 |
|---|---|---|
| 收窄走廊 | `level_run.gd` `_generate_maze` | `RUN_WIDTH` 5→4，中间通道 2 格 |
| 湿黑地面 shader | `level_run.gd` `_create_materials` | 复制 L1 `WET_SHADER` 调参（近黑全湿高反） |
| 客房门 + 墙裙腰线 | `_emit_wall` 覆盖 | 门框/门板/门牌 + 深色墙裙带（无碰撞） |
| 翻倒家具路障 | `_custom_build` | 文件柜/桌/纸张撒点，避主通道与出口前 3 格 |
| 天花板红灯板 | `_place_lights` 扩展 | 顶板纳入灯列表，参与熄灭 |
| 灯光熄灭逼近（方案 A） | 新增 `_physics_process` | 落后玩家 X 米的灯 `visible=false`；低吼音量随进度 |
| 追逐低吼音效 | `sound_generator.gd` | 新增 `create_entity_growl()`（低频循环，程序化） |
| 屏幕红脉冲（方案 A） | `hud.gd` + `hud.tscn` | 暗角 `ColorRect`，随 `GameState` 追逐强度闪 |
| 尽头门 + EXIT 牌 | `_place_exit` 覆盖 | 门板 + 绿光 EXIT `Label3D` |
| （可选）黑影剪影（方案 B） | `_custom_build` 预留 | 一个函数，默认不调用 |

## 6. 验证计划

1. 诊断脚本（跑完即删）：通道宽度、路障件数、客房门数、灯总数与熄灭序列长度、
   杏仁水/电池落位、出口在位、主通道无封死（沿中心线逐格 `is_floor` 全通）。
2. 六场景 headless 扫描零 `SCRIPT ERROR`。
3. 人工进游戏：冲刺跑到底，确认——身后灯逐盏熄灭、低吼渐强、
   路障擦身不卡、地面反光成条、尽头 EXIT 绿光可见、集齐杏仁水放行。

## 7. 不做清单（控制范围）

- **不做方案 C**（真寻路实体）：过度工程，见 §2。
- 路障/门/家具一律**无碰撞**：狂奔关卡撞了就废，纯视觉压迫。
- 客房门**不可进入**：不是关卡，是氛围。
- 不加新 ambientCG 素材：金属/混凝土/木纹全用已有目录 + 程序化。
- 不改其他关卡；基类仅允许新增可选钩子，不动现有流程。
- 追逐**不造成实质伤害/死亡**：本作无生命系统，纯恐怖氛围（跑不掉也不会死，
  只是永远"差一点被追上"的心理压迫）。
