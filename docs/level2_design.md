# Level 2「管道之梦」重做设计文档

> 目标观感：一条在黑暗里无限延伸的混凝土维护隧道。低矮的顶棚上爬满**直径半米的生锈工业
> 管道**，墙壁上成捆的电线电缆垂下；金属阀门每隔几米从管道上探出来，其中几处正**嘶嘶地
> 喷着蒸汽**。老旧的荧光灯管在头顶发出微弱而闪烁的绿光，照亮脚下潮湿斑驳的混凝土。空气
> 闷热潮湿，你每走一步，隧道的**回声**都比你慢半拍跟上来。远处——陷进纯粹的黑暗。
> 参考四张：巨型管道的走廊 / 密集管线+阀门+灯管 / 斑驳墙面+成捆电缆 / 黑暗中尽头的光。

## 2. 视觉支柱与实现方案

### 2.1 巨型工业管道（第一优先级，尺度是灵魂）

- **主管道**：`_pipe_line` 管径从 r 0.07~0.12 升级到 **r 0.25~0.35**（直径 0.5~0.7m），
  对应参考图里"把人挤在中间"的巨管。占走廊 ~0.7m，直接压迫通行感。
- **三档管径组合**（不再是一根细管）：主管 r 0.25~0.35 伴行次管 r 0.1~0.15、
  细缆管 r 0.05，沿墙排布成"管道簇"——参考图 1 那种一眼望不到头的管线丛林。
- **顶棚干线同步升级**：`_ceiling_conduit` 管径提升为 r 0.18~0.3 大管成排
  （对应"天花板布满巨大管道"），数量 16 → 22 条，覆盖率更高。
- 大管贴墙/贴顶，**保持通行**（绝不做横跨走廊的管子，见 §7）。

### 2.2 蒸汽（管道"活着"的证据，第二优先级）

- **喷口位置**：`_pipe_line` 带阀门的管（30%）+ 顶棚干线 15%，在管节/阀门处生成蒸汽源。
- **粒子实现**：复用 dust_field 的 `GPUParticles3D` 模式（[dust_field.gd:31](file:///d:/杂类/后室-godot4.7.2/generation/dust_field.gd#L31)）——
  白色半透明 quad、缓慢向上 + 随机扩散、lifetime 2~3s、预生成铺满、局部坐标。
  蒸汽粒子更密、更白、比浮尘大 3~4 倍。
- **嘶嘶声**：`sound_generator.gd` 新增 `create_hiss()`（窄带噪声 + 慢幅度调制循环），
  挂在蒸汽源位置 `AudioStreamPlayer3D`。全图 ~12 个蒸汽源 = 12 处持续的"活"。
- 蒸汽量克制：不是烟囱，是"某几处管道在喘气"，太密会挡视线。

### 2.3 回声感（听觉的阈限空间，第三优先级）

现状 `sound_generator.gd` 只有脚步/低频 hum/点击。新增：

- **混响 bus**：关卡 `_ready` 里 `AudioServer.add_bus_effect` 挂一个 `ReverbEffect`
  （`room_size` 大、`damp` 中高——混凝土隧道那种空荡感），全局脚步声/滴水都带尾巴。
- **滴水声**：新增 `create_drip()`（随机间隔的高频 ping + 长衰减），循环播放器挂在场景里，
  频率低（每 4~8 秒一声）——"闷热潮湿"的听觉注脚。
- **hum 调整**：音量 -14 → -16dB（更安静，衬托滴水/蒸汽/回声），音调 0.88 保留。

### 2.4 昏暗 + 老旧荧光灯（"少量、微弱、老旧"）

- `fill_light_energy` 0.15 → **0.08**（环境光压暗，灯下才亮）。
- `light_range` 9.0 → **7.0**（光程缩短，几步外就暗——"远处陷入黑暗"的直接手段）。
- `flicker_chance` 0.28 → **0.35**（更爱闪）。
- **灯板三态**（复用 L1 已验证的 FlickeringLight + sync_material）：常亮 40% /
  闪烁 35% / **熄灭 25%**（死灰灯管，不再只闪不灭）——"老旧"的实锤。
- **灯色老化**：emission 压暗 30%、色温往绿黄偏（`Color(0.72, 0.82, 0.66)`），
  灯管积灰质感。`light_panel_size` 缩小到 (1.0, 0.28)（老式窄灯管）。
- **灯密度降低**：基类 `_place_lights` 步长（`LIGHT_STEP` 或按格阈值）调稀——
  "少量荧光灯"，走廊大部分段落落在黑暗中，只有路口/管群处有灯。

### 2.5 墙壁斑驳掉灰

- 墙材换 **Plaster001**（斑驳石膏，**磁盘已有**，见素材清单）——比混凝土更"维护隧道"，
  掉灰剥落感天然自带。`l2_wall_mat()` 的 tint 压暗到 `(0.52, 0.5, 0.48)`。
- **近地霉斑墙裙带**：`_emit_wall` 底部 0.9m 高叠一条深色带（复用 L0 踢脚线思路，
  但更高更脏）——潮湿闷热在墙根留下的痕迹。
- **顶部水渍**（可选）：`_emit_wall` 顶部 0.3m 一条暗黄水渍带，呼应渗水/蒸汽冷凝。

### 2.6 金属锈蚀

- `_pipe_mat()`：`metallic` 0.6 → **0.3**、`roughness` 0.45 → **0.7**（锈蚀哑光，不再锃亮）。
- 色板重排：灰铁 30% / **锈红 40%** / 暗铜 30%——锈是主色，不是点缀。
- `_valve_mat()`：亮红 → **锈红暗红**（`Color(0.42, 0.08, 0.05)`），手轮旧得不反光。
- `_tray_mat()` 同理压暗去金属感。

### 2.7 狭窄迷宫长廊

- `cell_size` 4.0 → **3.4**：走廊净宽 = cell - WALL_THICK(0.28) ≈ **3.1m**（现在是 3.7m）。
- `wall_height` 2.6 → **2.4**：更低，顶棚管线更"压头"，巨型管 r 0.3 占满上部空间。
- 通行净宽再被 §2.1 大管侵占 ~0.7m → **实际通行 ~2.4m**，人像被管道夹着走。
- `maze_size` 12 → **13**：更长更绕；房间保持少（1~2 个，维护隧道不该有大厅）。
- `loop_wall_chance` 0.3 保留（迷宫感）。

### 2.8 远处陷入黑暗 + 阈限空间

- 雾 0.03 → **0.035** + 光程缩短（§2.4）双管齐下，直走廊 2~3 段后即隐入黑。
- `dust_extents` 收窄匹配新走廊：`(10, 1.2, 10)` → `(8, 1.0, 8)`，浮尘 400 保留
  （手电/微光下可见尘柱）。
- **阈限感**来自"重复 + 无尽头"：走廊单元高度统一（管线四态随机但尺码一致）、
  灯光稀疏、远处永远黑——看不到边界，就是阈限。

## 5. 验证计划

1. 诊断脚本（跑完即删）：管径 ≥0.2 的管道数量（巨管确实存在）、蒸汽源数量（~12）、
   走廊净宽（3.1m）、灯三态分布（40/35/25）、连通性 BFS 全可达、拾取物落位避开管群/蒸汽源。
2. 六场景 headless 扫描零 `SCRIPT ERROR`（重点：Reverb bus 挂载、GPUParticles 蒸汽、
   新材质加载）。
3. 人工进游戏：**竖着耳朵听**——回声、滴水、蒸汽嘶嘶；**用眼睛看**——巨管压走廊、
   灯灭一片、墙斑驳、远处黑。重点站在巨管旁的走廊里转一圈看通行感。

## 7. 不做清单（控制范围）

- **不做横跨走廊的大管**：撞头/卡通行，破坏狂奔手感（这关是 L ! 之外的"爬行关"）。
- **不做可交互阀门**：纯装饰，与全局"无交互系统"一致（有全局交互的只有拾取物/门）。
- 蒸汽**不做碰撞/伤害**：纯视觉 + 听觉氛围。
- 回声**不逐物做**：全局一个 Reverb bus 覆盖，不做距离感知混响。
- **不做方案级抉择**：描述已足够具体（昏暗/狭窄/蒸汽/回声全点名），
  默认全部按 §2 落地，无待拍板项。
- 不改其他关卡；基类仅允许新增可选钩子（三态灯已在 L1 实现过，直接复用）。
