# Level 1「无尽混凝土大仓库」设计文档

> 目标观感：经典后室 Level 1 最初发现时的样子——一眼望不到头的混凝土仓库，
> 规则柱网消失在薄雾里，满地积水倒映着忽明忽暗的荧光灯管。

## 1. 视觉支柱（参考图提炼）

| 元素 | 规格 | 实现 |
|---|---|---|
| 空间结构 | **开阔大平层**，不是迷宫走廊：柱网按固定间距排布，隔断墙拉出长巷道 | `WarehouseGenerator` |
| 混凝土柱 | 方形 0.8m 柱身 + 柱帽，纵向间距 ~16m，一眼看不到头 | 基类 `_build_pillars`（规则化） |
| 地面 | 湿混凝土：程序化水洼（噪声阈值），水洼区反照率压暗、粗糙度 0.04（灯光拉出长条高光）、干区粗糙度 0.9 | 自写 spatial shader，世界 XZ 平面投影采样贴图 |
| 顶棚 | 压暗的混凝土板，灯管吊在其下 | `l1_ceiling_mat` 调暗 |
| 墙面 | 混凝土（隔断墙/边界墙），沿用 `l1_wall_mat` | 基类薄墙合并 |
| 照明 | **荧光灯管**：2.4m 长白色灯管吊架，三态——常亮 40% / 闪烁 35%（灯管自发光与灯光同步熄灭）/ 熄灭 25%（熄灭管无自发光无光源） | 覆盖 `_place_lights` |
| 氛围 | 薄雾弥漫：体积雾密度 0.05，冷灰色调；浮尘 900 粒 | `volumetric_fog_density` / `dust_*` |
| 货架 | 沿隔断墙排布的重型货架巷道（参考图 3）：橙钢柱 + 4 层板 + 货箱；巷道号牌高位钉在巷道尽头墙面（4.2m，正对巷道，非 billboard） | `_custom_build` |
| 音效 | 低鸣 0.85 音高（比现在更低沉）；闪烁灯纯视觉，电流嗡声待补 | 基类 hum |

## 2. 布局规则（WarehouseGenerator）

1. 全图默认 FLOOR，仅四周一圈 WALL（边界）。
2. **规则柱网**：`x,y ∈ {3, 7, 11, …}`（间隔 4 格 = 16m）设 WALL 并登记进
   `pillar_cells`，由基类渲染成独立方柱。柱网天然不阻断通行。
3. **隔断墙**：在候选线（y=5,9,13… / x=5,9,13…）中随机取 ~45% 放置，
   每线 1~2 段墙（4~10 格长），段间留 3~6 格大缺口；记录到 `partitions`
   （`{horizontal, line, a, b}`）供货架贴靠。
4. 连通性：开阔地 + 带缺口隔断 + 稀疏柱网，天然全连通，无需兜底。
5. 出口/地标/引导流程全部复用基类（隔断墙正好给出口提供贴面）。

## 3. 水面 shader 要点（地面）

- `world_pos.xz` 平面投影采样混凝土贴图（地面水平，无需三向投影）。
- 水洼掩码：双频正弦伪噪声 `smoothstep` 出斑块，随世界坐标缓漂移（呼吸感）。
- 水洼内：`ALBEDO *= 0.55`（湿色变深）、`ROUGHNESS = 0.04`、
  法线加微扰（±0.06）模拟水面涟漪；干区 `ROUGHNESS = 0.9`。
- 贴图缺失回退：程序噪声贴图（与 MatLib 回退一致），保证无素材可跑。
- 不做真实镜面反射——靠低粗糙度 + 灯光 specular 高光拉出「倒影感」，
  性能友好且正是参考图的观感来源。

## 4. 参数速查（level_1.gd `_init`）

```
cell_size 4.0 · wall_height 5.0 · maze_size 14（29×29 格 ≈ 116m 见方）
light_color 冷白 (0.9, 0.95, 1.0) · light_range 13
volumetric_fog_density 0.05 · dust_count 900
hum_pitch 0.85 · flicker_chance 0.35
```

## 5. 不做清单（控制范围）

- 不做真实水面几何/折射（水洼是材质效果，玩家踩上去不减速——留给后续）。
- 不做 SSR/SDFGI 反射（性能与复杂度不划算，specular 方案够用）。
- 不改其他关卡与基类流程（除既有的 `_build_floor` / `_place_lights` 覆盖点）。
