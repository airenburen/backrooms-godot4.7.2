# Poolrooms「泳池房 / Level 37」v4 设计文档 —— 下沉泳池 · 上下两层 · 明亮暖阳

> 目标观感：白瓷砖砌成的无尽泳池殿，阳光从高窗斜射进来，水面晃眼；
> 每个开阔池舱中央是下沉的泳池盆（齐腰深），池缘环绕干爽瓷砖走道，
> 罗马阶梯下水，池底游走焦散光网，盆顶天花板投着游动的光斑网；
> 池中柱列从水里直通天花，宽桥洞口立着圆角大拱门。
> **v4：每个池舱上方都有一层二楼**（回廊环绕、中央大挑空俯瞰水盆），
> 折返梯/直跑梯上楼、跳板可跳进深水、**跨舱天桥把二楼连成一条可跑动的通路网络**，
> 出口搬到了二楼——想通关，先上楼。

## 1. 设计目标（v4 拍板结论）

v3 的病根与 v4 对策：

| 病根 | v4 对策 |
|---|---|
| 向上只有"最大舱一条 2.2m 回廊"，空间关系整体是**平**的 | **每个池舱都有二层**：回廊舱=沿池盆一整圈板（2 格宽，正压在一层干走道上）+ 中央大挑空；挑最大的 1~2 个舱做**双层舱**（二楼板向挑空悬挑 1 格，可用区 3 格宽，明显宽于一层走道） |
| 上下层没有"必须上去"的理由 | **出口搬到二楼**（3D 可达性校验 + 三级兜底）；3 瓶杏仁水里 1 瓶放二楼，上楼变成必答题 |
| 各舱二层若只是孤立看台，就仍是一堆"平"的平台 | **跨舱天桥**沿已有桥带中线架设，穿过拱门板上凿出的通行洞，把各舱二楼串成网络（MST 桥必建、环路桥随机建） |
| 全局水面 -0.12m 盖满全图 → 满地齐踝积水，没有"真泳池" | **水只存在于池盆里**：每舱内缩 2 格是干走道，中间下沉池盆；水面 -0.18 只铺在盆内 |
| 大厅间 2 格窄通道 → 迷宫感 | **4~6 格宽直通桥**连接开阔池舱，长视线、无窄廊 |

基调：**明亮暖阳**（用户拍板）——白瓷砖高反光、拱窗斜射阳光、水面晃眼、焦散打天花板。
v4 后高窗升到二层高度，光柱从二层窗斜穿挑空打进水面。

## 3. 生成算法（poolrooms_generator.gd，舱室图 + 深度图层 + 上层图层）

Grid 仍为 WALL/FLOOR 二值，完全兼容 MazeGenerator 接口（BFS/距离场/贴墙判定零改动）；
池盆/柱/桥/二层作为 **grid 之上的图层**输出：

```
generate(size=19, seed)
① 撒舱：矩形 10~16 格见方、间隙 ≥3 格，目标 6~9 个（放不下逐级缩，保底 2 个）
   —— 实测 39×39 地图自然密度为 3~4 个大舱（10~16 格 ≈ 45~72m），足够开阔
② 舱内凿 FLOOR
③ 连接：中心距 Prim MST + 1~2 条随机环路；每条边沿重叠轴带凿 4~6 格宽直开口
   （对角舱退化为宽 L 形桥）；失败兜底全桥接
④ 池盆：每舱内缩 2 格（四面 2 格宽干走道）得 basin（≥5×5 才成盆，否则旱厅）；
   盆缘 1 格环 depth=1(-0.35)，盆心 depth=2(-1.2)
⑤ 池中柱：3×3 格间距柱网撒在深水区（ring≥1，避开盆缘浅台）→ col_cells
   （8×8 盆 4 根、12×12 盆 16 根，神庙式柱林）
⑥ _plan_upper() 上层规划（顺序不可换：选双层舱 → 定楼梯 → 铺板 → 架天桥 → 连通修复）
   a 双层舱：halls 按面积降序取最多 2 个（长边 ≥12 格），且至少留一个回廊舱保证形态混合
   b 定楼梯：**每舱必有一条**（先定楼梯再铺板——找不到楼梯位的舱直接放弃二层，
     宁可在个别小地图上"平"一点，也不留上不去的板）；
     扫四条边找"外侧是墙且非桥带"的最长连续段：回廊舱占 2 格（折返梯）、双层舱占 3 格（直跑梯）；
     折返梯出口在段起端外侧，直跑梯出口在段末端外侧（两者都要求落点格确实有板）
   c 铺板：回廊舱 = depth==0 的干走道框（2 格宽，正好压在一层走道上）；双层舱 = 整舱铺板
     但把 basin 内缩 1 格的区域留成**挑空**（保证 col_cells 全落在洞里、池中柱穿过挑空）；
     栏杆沿线记进 upper_wells；楼梯占的格标 UP_WELL（板在此断开）
   d 天桥：候选 = `bridges`（普通桥）+ `l_bridges`（对角舱的 L 形兜底桥，**只给二层用**，
     不并入 bridges 以免多生成拱门、改动 is_bridge_cell）；沿桥带中线找两端第一个板格，
     中间格铺桥面。**桥带 size.x == size.y 时中线方向有歧义，必须两个轴向都试**
     （否则天桥接不上两端板，整舱二层会被迫降级）；MST 桥与 L 桥必建，
     环路桥 60% 概率建（跳过的记进 _skipped_bridges）；中线含楼梯井则跳过
   e 连通修复：**分块前先把 _skipped_bridges 里的桥补建**（把桥补上远比废掉整个舱的二层划算），
     仍不连通才只保留最大连通块、其余整体降级为无二层，
     并同步清理楼梯/天桥/挑空记录——绝不留下上不去的孤立二层
```

输出图层：`halls / basins / bridges / col_cells / depth: PackedInt32Array`（v3）
＋ `upper: PackedInt32Array`（UP_NONE/UP_SLAB/UP_WELL）、`upper_halls / upper_wells /
upper_stairs / upper_bridges / upper_bridge_cells / l_bridges`（v4）。
关键性质：池盆距舱墙 ≥2 格 → `find_farthest_floor`/`find_nearest_floor` 天然倾向走道，
落位层再做 BFS 走道校验兜底（见 §7）。

## 4. 几何装配（level_poolrooms.gd）

分区域大 CSG，不逐格铺。**v4 原则：不需要布尔运算的构件（楼板/栏墙/楼梯/天桥/跳板/灯具）
一律 `MeshInstance3D + StaticBody3D + CollisionShape3D(BoxShape3D)`，不占用 CSG 预算**；
连天井洞口也是靠"楼板矩形合并时跳过空格"拼出来的，不做布尔减法。

- **厚地板 slab**：全图一张（顶 0 / 底 -1.4），走道面即其顶面
- **每盆**（`_build_basin`）：
  1. SUBTRACT 盒凿到 -1.2（slab 底 -1.4，留 0.2 底板）
  2. 浅台：盆缘一圈 1 格宽 ADD 盒补回 -0.35（四面各一根通长盒 ×4）
  3. 池底焦散衬板：MeshInstance PlaneMesh @ -1.18（`caustics_mat`，不占 CSG 预算）
  4. 水面：**每盆一张独立 PlaneMesh quad** @ -0.18（`WATER_SHADER`，
     foam 用 UV 边缘距离 → 自动贴池缘；`mesh_size`=盆世界尺寸，foam 0.7 / wave 0.02）
  5. 盆顶焦散光网：天花下 0.05m 朝下 additive quad（`caustics_glow_mat`，纯 emission）
  6. **罗马阶梯** ×2（南北各一条）：6 级 ADD 盒，踏高 1.2/7≈0.171（玩家胶囊可攀），
     踏深 0.5、宽 2.4，最后一级落差由池底补齐
- **池中柱网**：col_cells 每格一根 CSGCylinder（r 0.45，池底直通天花 = 高 10.7m，
  自动穿过挑空）
- **二层系统**（`_build_upper`，v4；**在 `_custom_build` 里建**，因为天桥要在已立好的
  拱门板上凿洞，装配顺序不能提前）：
  1. 楼板：`_slab_rects()` 把上层图层里连续格**贪婪合并成大矩形**（整圈回廊被切成 4 条
     边，不逐格铺），板顶 UPPER_Y、厚 T_SLAB，每块 1 个 MeshInstance + 1 个静态碰撞
  2. 栏墙：沿每块 `upper_wells`（挑空的四条边）建 1.1m 高栏墙；**跳板根部留 2.0m 缺口**
     （这就是下水口；一层罗马梯在 6m 之下，与栏墙不同层，不需要留缺口）
  3. 楼梯：回廊舱折返梯（2 跑 × 17 级，踏高 6.0/34≈0.176、跑宽 2.1）/ 双层舱直跑梯
     （34 级，踏深 13.5/34≈0.4）；逐级独立 BoxMesh + 逐级 CollisionShape（手感优先，
     不做斜置单斜面）；朝舱内一侧加 1.0m 护栏（靠墙侧有墙）
  4. 天桥：桥面只铺 `_in_any_hall` 为假的**间隙段**（两端舱内已有楼板，不重叠免 z-fighting）
     + 两侧栏墙；桥面顶 UPPER_Y、底 5.6 ⇒ 桥下 5.6m 净高过人
  5. 拱门通行洞：`_punch_arch` 在拱门板上挂 CSG SUBTRACT（**必须用 board 的局部坐标**），
     洞 5.6~8.4（净高 2.8），宽 = 桥宽 + 0.5 ⇒ 天桥从拱楣带上方的洞里穿过
  6. 跳板：从最大的两块挑空的长边中点伸 2 格（9m）向水面上空，面 UPPER_Y、宽 1.4，
     下挂两根斜撑（`rotation.x/z` 按伸出轴倾斜）；只下不上，落水 6.18m 不淹没

v3.1 修复备忘（仍然有效）：凿盆 SUBTRACT 盒是 slab 的子节点，**必须用 slab 局部坐标**
（世界坐标会把盒子甩到地图外，坑凿不出来、地面全平）；焦散 shader 的 `caustic()`
输入须先 `mod(p, TAU) - 250.0` 折回原版魔数窗口（大坐标直接迭代发散 → 天花"水板"全白）；
回廊板格范围判定注意浮点整格线（ceil 前先扣 0.005m 容差）

v4 踩坑备忘：`Rect2i(position, w, h)` 这种三参构造**不存在**（只有 `Rect2i(Vector2i, Vector2i)`
和 `Rect2i(int,int,int,int)`），写错会让整个关卡脚本编译失败、而 headless 诊断会**假通过**
（fail=0 但实际什么都没跑）——所以诊断必须打印每轮的关键计数，不能只看退出码。

CSG 实测预算：v3 为 286~363；v4 因灯具全面 Mesh 化（省 ~90）＋新增拱门通行洞（+2/座桥），
实测降到 **96~184**（6 种子），安全线 420、上限 500 ✓

## 5. 光照与材质

- **暖阳**：DirectionalLight3D（色 1.0/0.94/0.80，energy 1.4，rot -35°/28°，唯一开影灯）
- **主灯**：方灯板（嵌顶暖白）/ 吊球灯（细线 + 乳白球）50/50，energy 2.0~2.6，不开影。
  **v4 起灯具全部 Mesh 化**（BoxMesh / CylinderMesh / SphereMesh，省下 ~90 个 CSG 名额）
- **两层补光（v4 必做）**：天花升到 9.5 且有楼板遮挡，一层若只靠顶灯就是黑胡同，
  所以 `_place_lights` 拆成 `_place_layer_lights` **跑两遍贪心覆盖**：
  | 层 | 判据 | 灯高 / 灯板高 | 覆盖半径 |
  |---|---|---|---|
  | 一层 · 上方无板 | `not upper_slab` | 9.15 / 9.44（天花） | 0.8 × light_range |
  | 一层 · 上方有板 | `upper_slab` | **5.25 / 5.54（板底）** | 0.8 × light_range |
  | 二层 | `upper_slab` 且非井口 | 9.15 / 9.44（天花） | **1.6 × light_range**（更稀、省体积雾开销） |
  吊球灯的球心仍在一层 3.0m / 二层 UPPER_Y+2.5，吊线长度按当前"天花"自动算
- **光柱**：高窗暖白 emission 板（**y 7.3，二层窗**）+ SpotLight 从窗口（y 7.2）斜射厅心挑空，≤6 束
- **白瓷砖**（material_lib）：墙 tint (0.97,0.95,0.90) roughness 0.18；
  地 tint (0.90,0.89,0.85) roughness 0.28；均基于 Tiles018 贴图 + 世界三向投影
  （二层楼板/楼梯/天桥沿用 `pool_floor_mat`，BoxMesh 无所谓 UV）
- **焦散**（material_lib）：
  - `caustics_mat()`：世界 XZ 三层网纹 shader，叠在池底瓷砖上
  - `caustics_glow_mat()`：additive emission 光斑网，投在盆顶天花上
- **雾/尘**：fog 0.003（视距变长后调薄）、dust 150（extents.y 提到 3.2，两层都见尘）

## 6. 装修件

- **圆角大拱门**（桥口签名）：桥口（4~8 格宽开口、两端有墙夹）立一块通高瓷砖板，
  SUBTRACT 大矩形洞（洞顶 5.2m - 角半径）+ 两角半圆柱 → 圆角大门洞，两侧自然留 0.9m 门垛。
  **v4：拱门板同时是二层天桥的"门框"**——天桥穿过时在板上再凿一个 5.6~8.4 的通行洞，
  5.2~5.6 留成拱楣带（`_punch_arch`，洞用 board 局部坐标）
- **高窗光柱**：每舱随机一侧贴 3 块暖白 emission 窗板（y 7.3 = 二层），60% 配斜射 SpotLight
- **墙上黑洞口**（≤3 处）：`_emit_wall` 钩子，长墙凿 0.9×1.35 黑洞 + 黑背板封死（仍在一层）
- **跳板**（v4）：最大两块挑空的长边中点各伸一条 9m×1.4m 悬臂板 + 两根斜撑，
  栏杆在该处留 2.0m 缺口——这是二层唯一直通水面的路，也是"跳下去最爽"的一条
- **格栅吊顶**：`pool_ceiling_grid_mat()` 冷白 50cm 方格

## 7. 落位规则（v4 全面楼层化）

- `_is_walkway(cell)`：`depth_at == 0` 且非柱格（**一层的**可行走判定）
- `_blocked_at(cell, layer)`：禁放查询（layer=1 查 `upper_slab`，layer=0 查走道）
  ＋ 楼梯投影格（`_ground_blocked`，从 `upper_stairs` 的 rect 派生）
- **3D 可达图**（`_build_reach`，在 `_position_player` 末尾建）：节点 =(格, 层)，
  地面 4 邻接（含池盆可蹚水，排除池中柱）+ 二层板 4 邻接（天桥面就是板，天生连通）
  ＋ 楼梯 `bottom ↔ top` 双向。地标/出口全部改用它，**不再用 2D 距离场**
  （2D 会把玩家引到出口正下方的一层打转）
- **出生点**：一层干走道（`_nearest_walkway`）
- **出口搬到二楼**（v4 核心改动）：`_pick_exit_cell` 在"3D 可达的二层格"里选步数最远的
  贴墙格，且要求贴的那面墙**不全是桥带**（否则门会立进拱门洞里）。
  兜底链：可达二层格为空 → 本舱回廊 → 再空 → 退回一层出口并 `push_warning`（绝不留死局）
- **基类出口钩子**（最小侵入）：`level_base.gd` 新增零行为钩子 `_exit_base_y()`（默认 0）
  / `_exit_box_h()`（默认 `wall_height`），`_place_exit` 里的 `wall_height*0.5/0.9/0.35`
  改由 `_exit_box_h()` 按比例算 ⇒ **其它 5 关行为完全不变**（已 headless 回归验证）；
  泳池关返回 `UPPER_Y` / `2.6`
- **拾取物**：`_spawn_pickups` 覆盖——二层 1 杏仁水 + 2 电池（`y_off = UPPER_Y`）、
  一层 1 杏仁水 + 2 电池、**第 3 瓶杏仁水泡在最大盆中心深水格**（y = WATER_Y + 0.08，
  得下水捞）；间距规则沿用基类（离 spawn ≥3、离 exit ≥2、互相 ≥4 格）
- **地标**：`_place_landmarks` 覆盖为 3D 版（`_trace_path_3d` 走 3D 梯度），
  并在每个楼梯顶（`upper_stairs[].top`）立一个发光信标，把"这里要上楼"明确指出来
- 一层罗马阶梯入口**不需要**在二层栏墙上留缺口（栏墙在 6.0m 高，与一层下水路不同层）
