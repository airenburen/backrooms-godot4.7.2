# Poolrooms「泳池房 / Level 37」重做设计文档

> 目标观感：暖奶油瓷砖砌成的无尽水殿，齐踝静水把吊球灯和拱门倒影拉成
> 一片晃动的青绿；圆柱柱廊从水里长出来，池底游走着焦散光网；
> 大厅明亮通透（图 3/4），越往深处越幽暗，一束束侧光斜切进黑暗打在柱身上
> （图 1），方形灯板嵌在防水格栅顶里，远处弧形隔断墙把视线拐走（图 2）。
> 参考图四张：明暗侧光柱廊 / 暗调方灯板+弧形墙+焦散 / 暖色拱券壁龛长廊 / 双拱门吊球灯。

## 1. 现状盘点（已经做对的，和还差的）

现状 = 暖奶油瓷砖 + 全域齐踝积水 + 水中圆柱 + 吊球灯 + CSG 凿深水池 + 水面 shader。
**地基是对的**（漫水、柱廊、暖砖都在），但对照四张参考图，缺了 Poolrooms 的三样灵魂：

| 参考图签名元素 | 现状 | 严重度 |
|---|---|---|
| **垂直层次**（上下楼：干爽上层厅 / 大楼梯 / 阳台拱窗俯瞰水面） | 全图一个平面，只有往下凿的池盆 | ★★★ 点名的"太平" |
| **圆拱门 / 拱券壁龛**（图 3/4 的核心，厚墙里凿出的半圆拱） | 全是直角方门洞 | ★★★ 最大差距 |
| **水下焦散光网**（图 1/2 池底柱基上流动的亮纹） | 水面只有碎波，水下定死 | ★★★ 视觉灵魂 |
| **明暗对比 / 斜射光柱**（图 1 一束束切进黑暗） | fill_light 0.30 太平，全图均匀亮 | ★★ |
| 方形吊顶灯板（图 2） | 只有吊球灯一种 | ★ |
| 弧形隔断墙（图 2 看不透的弯墙） | 全直角 | ★ |
| 静水镜面倒影（图 3 平如镜） | 波太碎 | ★ |
| 防水格栅吊顶（图 3 方格顶） | 顶 = 瓷砖墙同款 | ★ |
| 墙上纯黑洞口（图 1 的未知通风口） | 无 | ★ |

空间尺度也偏小：图 3/4 是"望不到边"的大池，现状大厅 6–11 格偏局促。

## 2. 基调决策：分区过渡（**待拍板**，影响 §4 全部灯光参数）

四张参考图自相矛盾——图 3/4 暖亮通透，图 1/2 冷暗幽闭。三选一：

- **方案①「分区过渡」（推荐）**：大厅区暖亮（图 3/4 的阈限宁静），
  越往地图深处/远端越暗越冷（图 1/2 的恐怖压迫），焦散与光柱在暗区最出彩。
  一个关卡同时给到两种情绪，靠"距离出生点的远近"做明暗梯度。
- **方案②「纯暖明亮」**：全程图 3/4 那种发白的宁静，恐怖感靠空旷与重复，不靠黑。
- **方案③「冷暗为主」**：压到图 1/2 的幽闭，灯少而孤，大部分在水下的黑里。

> 默认按**方案①**写参数；§4 会标注"选②/③时怎么调"。**这是本关唯一需要你点头的方向选择。**

## 3. 视觉支柱与实现方案

### 3.1 圆拱门 / 拱券（图 3/4 签名，本关第一优先级）

- **真·拱券门套**（不碰现有逐格墙体，纯叠加装饰件）：在"通道格与大厅格交界的门洞"
  处，放一块**拱形挡板**——一个厚 = 墙厚的瓷砖块，底边用 CSG 布尔
  `SUBTRACT` 一个横放的半圆柱，剩下的两个上角正好把方洞补成**半圆拱洞**（图 4 效果）。
  拱内壁自动是 CSG 表面、贴瓷砖，无需额外处理。
- **拱券壁龛**（图 3 那排"假窗"）：大厅侧墙每隔 2~3 格，贴一块内凹的半拱壁龛
  （浅 CSG 盒 SUBTRACT 半圆柱，凹进去 0.3m），龛顶藏一条暖光灯带（`emission` 薄板）——
  远看就是图 3 那一排发光的拱形 alcove。壁龛是死的，进不去。
- 生成点：`_custom_build`（拱券门套）+ 复用 `_emit_wall` 钩子（壁龛，沿墙撒）。

### 3.2 水下焦散光网 caustics（图 1/2 灵魂，第二优先级）

- **贴在"被照的水下表面"**：焦散是光透过波动水面在池底/柱基/墙根投出的流动亮网。
  shader 不能跨物体投影，所以给**水下的那几类表面**换带焦散的材质：
  - 池底（`_build_floor` 的地板，水面以下部分）
  - 柱子的水下段（柱基 ~ 水面以下）
  - 墙根水线以下一条带
- **实现**：新增 `caustics_mat()`（ShaderMaterial）——世界坐标 XZ 上叠 3 层
  不同频率/方向的 `sin`+`Voronoi`近似（用 `abs(fract(p)-0.5)` 折线模拟网纹），
  随 `TIME` 缓慢平移错动，得到游动的亮网；亮网处 `ALBEDO` 提亮 + 轻微青绿 tint、
  `ROUGHNESS` 降低。叠加在原有瓷砖色之上（shader 内 `texture(albedo_tex, ...)` 采样瓷砖）。
- 这是**纯 shader 零贴图零素材**，性能友好（无真实光线追踪）。

### 3.3 明暗对比 + 斜射光柱（图 1，配合方案①基调）

- **压低环境光**：`fill_light_energy` 0.30 → 0.12，让"灯下亮、几步外就暗"。
- **主灯提能**：`light_energy_range` 上调，`omni_range` 收一点，光斑更集中。
- **斜射光柱**：沿墙在高处（~3.8m）随机放几盏 `SpotLight3D`，向下 45° 斜射、
  张角窄、`attenuation` 高——在雾里打出图 1 那种"一束光斜切打在柱身上"的体积光刃。
  数量克制（每图 4~6 束），`shadow_enabled` 开（光柱要有形）。
- **雾微增**：`volumetric_fog_density` 0.006 → 0.010，让光柱可见又不糊。

### 3.4 方形吊顶灯板（图 2，与吊球灯并存）

- 现状吊球灯保留；`_place_lights` 里加**第二种灯**：50% 概率改放
  嵌在格栅顶里的**方形发光板**（`CSGBox3D` 薄板 + 冷白 `emission`，贴顶），
  对应图 2 天花那块方灯。两种灯随机，丰富顶部节奏。

### 3.5 防水格栅吊顶（图 3 方格顶）

- 顶棚从"瓷砖墙同款"换成**程序化格栅**：复用 L0 的 `ceiling_grid_mat()` 思路，
  调成冷白防水板（更亮、格线更细），呼应图 3 的方格吊顶。零新素材。

### 3.6 弧形隔断墙 + 墙上黑洞口（图 1/2 点缀）

- **弧形隔断**（图 2）：≥6 格大厅内，30% 放一道弧形瓷砖隔断——
  `CSGCylinder3D` 薄壳（`radius` 大、只取一段弧，靠 `CSGPrimitive3D` 的
  角度裁切或简单用几段短盒近似弧排），立在水里，把视线拐个弯。无门、绕得过去。
- **黑洞口**（图 1）：每图 2~3 处，某面长墙上放一个纯黑凹洞
  （CSG SUBTRACT 一个方洞 + 深处一块 `albedo≈0.02` 黑背板）——
  "这里面通向哪？"的叙事钩子，进不去（洞深 0.5m 封死）。

### 3.7 静水倒影（图 3）

- 水面 shader：`wave_height` 0.035 → 0.022（更平静），`ROUGHNESS` 下限压到 0.02；
  可选在关卡里加一个低分辨率 `ReflectionProbe`（覆盖大厅），让静水真映出拱门与柱廊——
  图 3 的镜面感。性能敏感则跳过（靠低粗糙度 + 菲涅尔近似）。

### 3.8 空间放大

- `maze_size` 15 → 17，`cell_size` 4.0 → 4.5，`wall_height` 4.6 → 6.0（见 §3.9 需要层高）；
  大厅 6–11 格 → 8–14 格（改 `poolrooms_generator.gd`）。图 3/4 那种"望不到边"的大池。

### 3.9 垂直空间·上下楼（★ 本关头号新增，解决"太平"）

现状全图一个平面（只有往下凿的池盆），缺"上楼"的层次。引入**两级台地体系**：
部分大厅抬升成**干爽上层厅**（高出水面 ~2m 的实心瓷砖台地），大楼梯上下连通，
上层边缘开拱窗俯瞰下层水面——垂直动线 + 垂直视线一次到位。

#### 3.9.1 上层厅（raised hall / 台地）

- 约 **35~45% 的大厅**（≥8 格）判为"上层"，其余保持"下层"（现状齐踝水大厅）。
- 上层厅 = 一块**实心台地**：`CSGBox3D` 从下层水面一直堆到 `FLOOR_TOP + UPPER_RAISE`
  （`UPPER_RAISE = 2.0`，台面约 +1.75m），**顶面可走（碰撞开）、四壁贴瓷砖**，
  台面**干爽无积水**（全局水面在 -0.12，远低于台面，天然不淹）。
- 台地四壁**不是死墙**：朝下层敞开的边挖 **3~4 个半圆拱窗洞**（§3.1 拱券复用），
  从下层仰看是"一排水上拱廊"，从上层俯看是"栏杆外的水殿"——垂直视线的主角。
- 台地顶面边缘（临空侧）加 **1.0m 瓷砖栏墙**（矮墙，非玻璃），防坠落 + 剪影好看。

#### 3.9.2 大楼梯（grand staircase，"上下楼"的字面担当）

- 每个上层厅**至少一条主楼梯**：在其连接走廊的入口处，宽 **2.6m**、
  **11~12 级 × 0.16m 踏高**（≈2m 抬升），实心瓷砖台阶带碰撞，可走。
- 楼梯两侧各一道 **0.5m 厚瓷砖梯梁**（斜向实体，视觉上"嵌进台地"），
  楼梯正对的下层地面撒一圈**暖光地灯**（照亮上楼的路，弱指引升级）。
- 可选**双跑大楼梯**（40% 概率）：跑一半到平台、折返再跑——图 3 那种气派。

#### 3.9.3 挑空与高窗（下层厅的垂直感，图 1 光源）

- 下层厅层高随全局 `wall_height` 抬到 6.0m，**墙顶 4.5m 处一排拱形高窗**
  （内凹半拱 + 冷白 emission 薄板），配 §3.3 斜射 SpotLight 从窗口打下来——
  光柱落在下层水面与柱基上（焦散 §3.2 接住），就是图 1 的"斜切进黑暗的光"。
- 上层厅台底（台地 underside 朝下层那面）挂**筒灯点阵**，给下层补冷光。

#### 3.9.4 水中干岛（下层厅的"干屋"，Poolrooms 超现实点）

- 深水池（现状 -1.1m 池盆）保留，但**只出现在下层厅**（与上层厅互斥，避免"台地上凿坑"）。
- 新增**水中干岛**（12% 下层厅）：厅中央一块台面 **+0.15m**（高于水面 -0.12，故干爽）的
  实心瓷砖平台，四周被浅水环绕、由两级 0.08m 台阶从周围水面登上，平台边缘一圈坐台矮墙——
  "趟水走到中央，脚下突然干了"，Poolrooms 经典超现实点。
  （**注**：刻意不做"水面以下的干屋"——台面必须高于水面才谈得上干爽，否则必淹，物理不自洽。）

#### 3.9.5 连通性与玩法约束（关键，别把自己封死）

- 上层厅**必有 ≥1 条楼梯**（生成时强制），否则 2D 可达但 3D 上不去=死局。
- 出生点、出口**强制落在下层**（不淹、不悬空；出口若在上层厅则楼梯直通）。
- 杏仁水/电池/地标按**格所在层**落地：`_landmark_y_offset()` 从常量改为
  **按格查层**（下层返 `FLOOR_TOP`、上层返 `FLOOR_TOP + UPPER_RAISE`、干岛格返 `+0.15`），
  拾取物瓶子在各层台面/水面上各自浮对高度。
- 楼梯台地会**遮挡 2D 地标布点**——上层厅格并入 `_landmark_blocked`（地标只放下层开阔处）。

## 6. 验证计划

1. 诊断脚本（跑完即删）：大厅数与面积、**上层厅数 / 楼梯数（每上层厅 ≥1）/
   台地拱窗洞数 / 干岛数**、**3D 可达性抽查**（上层厅台面格经楼梯 BFS 能从出生点到达）、
   拱券门套数、壁龛数、焦散材质覆盖的表面数、斜射光柱数、方灯板 vs 吊球灯配比、
   弧形隔断数、黑洞口数、2D 连通性 BFS（全可达）、深水池/柱廊/上层厅格禁放地标仍生效、
   拾取物落位避开拱券且 y 按层正确。
2. 六场景 headless 扫描零 `SCRIPT ERROR`（重点：新 `caustics_mat` shader 编译、
   CSG 布尔拱券不报错）。
3. 人工进游戏：出生大厅（暖亮）→ **上大楼梯到上层厅俯瞰下层水面拱窗** → 游向深处（转暗）
   → 确认拱门倒影、池底焦散游动、至少一束斜射光柱、壁龛灯带、一处黑洞口、一处水中干岛；
   趟水过拱门不卡碰撞、楼梯不上头（栏墙挡得住）。

## 7. 不做清单（控制范围）

- 焦散**不做真实光线追踪/投影**，纯 shader 模拟（性能与复杂度红线）。
- 拱券/壁龛/黑洞口**一律不可进入**，纯环境叙事。
- 不下载新 ambientCG 素材：瓷砖复用 Tiles018/008，焦散/格栅/光柱全程序化。
