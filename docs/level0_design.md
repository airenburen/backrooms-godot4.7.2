# Level 0「经典黄色迷宫」重做设计文档

> 目标观感：后室原点——望不到头的 mono-yellow 房间簇，掉格吊顶里嵌着
> 忽明忽暗的荧光灯板，墙皮局部撕裂露出水泥，隔断墙上凿着没有门的方形门洞。
> 参考图四张：撕裂墙皮 / 梯子与天花洞口 / 踢脚线与隔断 / 方形门洞与格栅吊顶。

## 1. 现状问题（为什么现在是"换皮仓库它爹"）

当前 Level 0 = 基类默认配置：完美迷宫走廊（递归回溯生成）+ 贴顶悬挂面板灯。
与经典 L0 的差距：

| 经典 L0 | 现状 |
|---|---|
| **房间簇 + 隔断墙**，空间忽大忽小、拐角盲眼 | 等宽走廊迷宫，一眼假 |
| 隔断墙上的**方形门洞**（无门，纯洞口） | 走廊交叉口 |
| **掉格吊顶**（60cm 矿棉板格栅），灯板**嵌入**格栅 | 平整天花板 + 悬吊面板 |
| 墙根**踢脚线** | 无 |
| **mono-yellow 多色带**（黄/黄绿/土黄分区，"像但不是同一条走廊"） | 全图单一色调 |
| 墙皮**撕裂破洞**露水泥（图 1 签名景观） | 无破损 |
| 出口是**黑暗洞口** | 绿光 EXIT 面板（太游戏化） |

## 2. 视觉支柱与实现方案

### 2.1 布局：新 `Level0Generator`（levels/level0_generator.gd）

房间簇结构，接口完全兼容 `MazeGenerator`（grid/pillar_cells/距离场/寻路），
基类墙体/地标/出口流程零改动可用：

1. 37×37 格（`maze_size 18`，cell_size 4.0 → ~148m 见方）先全填 WALL。
2. **房间装箱**：先塞 4 个 6~8 见方大厅（柱阵载体），再用 3~8 格随机房
   填缝到目标 14~22 间；全部互不重叠、间隔 ≥1 格（间隔自然形成盲眼角落与隔断）。
3. **连通**：每间房连向已放置房间中质心最近的一间（贪心最近邻），
   L 形 1 格宽通道穿过间隔墙；35% 概率再连第二间（环路，多绕行路线）。
4. **大房装修**：≥6×6 的房间 70% 出**柱阵**（柱间空 2 格、距墙 ≥1 格，
   柱格记 WALL + pillar_cells 走基类独立方柱渲染）；不出柱阵则 50% 加一道
   1 格厚**矮隔断**（长 2~4 格，两端留口），特大房 30% 再加第二道；小房同样可出隔断。
5. **死胡同 alcove**：18% 房间向外凿 1×3~1×5 格盲端凹室
   （途中撞到非墙格即放弃，保证不破坏其他结构）。
6. 连通性由"每房必连"保证，无需兜底。

### 2.2 掉格吊顶 + 嵌入式灯板

- **格栅纹理程序化生成**（MatLib 新函数 `ceiling_grid_mat()`）：
  Image 直绘 60cm 矿棉板——浅米灰底 + 板面细噪点 + 2cm 深灰格线，
  平铺 1/0.6 tiles/m。**不需要下载新素材**（可选升级：ambientCG
  WallCeiling 分类自选一款，实现时先去官网核实 ID 再写进代码，勿编造）。
- **灯板嵌入**：面板尺寸 0.6×1.2m（2×4 英尺格栅灯），贴顶嵌平（不再悬吊 0.25m）；
  三态沿用仓库验证过的比例：常亮 55% / 闪烁 30% / 熄灭 15%（熄灭板用灰死面板材质）。
  闪烁灯管同步 `sync_material`（上轮给 FlickeringLight 加的，直接复用）。
- 布灯密度：地图放大后 `light_range` 保持 10.0（覆盖半径同步放大），
  灯随房间簇分布，忽明忽暗的碎灯感靠三态比例撑住。

### 2.3 踢脚线（覆盖 `_emit_wall` 钩子）

每段合并墙生成后，沿墙根追加一条 0.14m 高 × 0.06m 出墙的深色带
（脏米黄 `Color(0.35, 0.30, 0.20)`，roughness 0.8）——两端各缩 0.02m 避免转角 z-fight。
柱体（`_build_pillars`）同款柱脚圈。Level 2 用这个钩子挂管线，L0 用它画踢脚线，互不打架。

### 2.4 壁纸多色带

色带尺度随地图缩放：`band = maze.width / 3.5`（37 格时 ≈10.6），
墙段按中点格坐标 `floor(((a+b)/2)/band + line/band) % 3` 分 3 个色调区
（黄 / 偏绿黄 / 偏土黄），
同一 Plaster001 贴图、三种 tint（0.86/0.79/0.52 → 0.78/0.78/0.50 → 0.82/0.74/0.48）。
实现：`_emit_wall` 里按格坐标选 `_zone_mats[zone]`。
"看起来是同一条走廊，颜色却悄悄变了"——阈限感的精髓。

### 2.5 墙皮撕裂破洞（图 1 签名景观）

- 每段 **长度 ≥3 格的墙**，8% 概率在随机高度 1.2~2.0m 处贴一块破洞贴片：
  1.2×1.0m 的 `Decal3D` 方案否决（程序化撕裂贴图成本高），改用**实体贴片**：
  一块略出墙面 0.02m 的深灰水泥板（`Concrete030` 已有素材，tint 压暗），
  边缘叠 3~5 条不规则"翘起壁纸条"（细长 CSGBox，黄色，随机旋转 ±25°，
  从破洞边缘向外翻卷）——远看就是图 1 的撕裂感。
- 破洞只打在**走廊侧墙面**，位置避开出口格与出生格 2 格内。

### 2.6 出口：黑暗洞口（替换绿色 EXIT 面板）

- 覆盖 `_place_exit`：墙上开一个 2.4×3.0m 的**纯黑洞口**——
  黑色背板（albedo 0.02）+ 洞口内框一圈暗黄微光边条（emission 0.3，
  暗示"里面有东西"而不是"这里有 UI"）。
- 保留 `EXIT` Label3D 但改成暗黄色、亮度减半（可辨识性兜底）；
  触发盒逻辑不动（`CharacterBody3D` 早返回守卫保留）。

### 2.7 装饰件（`_custom_build`）

- **靠墙梯子**（图 2）：15% 房间放一把木梯贴墙立着（两侧竖杆 + 6 横档，
  纯装饰不可攀爬，无碰撞），高 ~2.95m 顶着 3.0m 吊顶——"通向哪里？哪儿也不通"。
- **墙面开关/插座**（图 4）：30% 长墙随机位置一个 8cm 白色小方片贴墙。
- 地标系统（黑碑/门框/信标）保留不动——它们与破洞、梯子共存，都是弱指引。

## 4. 实现钩子映射（动代码时照此执行）

| 内容 | 位置 | 方式 |
|---|---|---|
| 房间簇布局 | `levels/level0_generator.gd`（新） | 继承 `MazeGenerator`，覆盖 `generate()` |
| 格栅吊顶 / 破洞水泥 / 梯子木料材质 | `material_lib.gd` | 新增 3 个函数（格栅程序化，破洞用已有 Concrete030） |
| 吊顶材质、灯三态、踢脚线、色带、破洞、梯子、黑暗出口 | `level_0.gd`（从 2 行扩写） | 覆盖 `_create_materials` / `_place_lights` / `_emit_wall` / `_build_pillars` / `_custom_build` / `_place_exit` |
| 灯板嵌顶 | `_place_lights` 内 panel.position.y = 墙高-0.04 | 不再 `light.add_child` 悬吊 |

## 5. 验证计划

1. 诊断脚本（跑完即删）：房间数、门洞数、连通性 BFS（可达=全部）、
   灯三态计数、破洞/梯子/踢脚线计数、出生/出口格不在墙内。
2. 六场景 headless 扫描零 `SCRIPT ERROR`。
3. 人工进游戏：出生房 → 穿两个门洞 → 确认拐角盲眼感、吊顶格栅、踢脚线、
   至少一处破洞、出口黑洞口观感。

## 6. 不做清单（控制范围）

- 不做真实可攀爬梯子/可交互门（纯环境叙事）。
- 不做 Decal 撕裂贴图（实体贴片方案够用且零素材依赖）。
- 不改其他关卡；基类仅允许新增可选钩子，不动现有流程。
- 不下载新 ambientCG 素材（全部程序化或复用已有 13 个目录）。
- 完美迷宫走廊彻底退役，但**不删** `MazeGenerator`——它是 L1/L2 的基类。
